# Security

For deployment practices, threat summary, and environment variables, see **[docs/SECURITY.md](docs/SECURITY.md)**.

## Reporting a vulnerability

- Prefer **[GitHub Security Advisories](https://github.com/advisories)** on this repository (if enabled) or open a **private** security report to the maintainers.
- Include affected version/commit, reproduction steps, and impact; we aim to acknowledge within a few business days.

## Supported versions

- **Main branch (`main`)** receives security fixes as they are identified. Use the latest tag or commit for production.
- Older commits are **best-effort**; upgrade when possible.

Do not disclose unfixed vulnerabilities publicly until a fix is available.
